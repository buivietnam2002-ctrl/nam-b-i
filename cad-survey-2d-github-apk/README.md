# CAD Survey 2D - Phần mềm Khảo sát & Thiết kế Tủ bếp

## Hướng dẫn lấy file `.apk` trên GitHub Actions
1. Giải nén file `.zip` và tải toàn bộ các tệp lên kho lưu trữ GitHub (`buivietnam2002-ctrl/nam-b-i`).
2. Mở tab **Actions** trên GitHub, chọn tiến trình **Build Android APK**.
3. Chờ khoảng 2–3 phút để tiến trình hoàn tất (tích xanh), kéo xuống mục **Artifacts** và tải **`CAD-Survey-2D-Android-APK`** về cài đặt trên điện thoại Android.
